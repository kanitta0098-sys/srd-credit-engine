# SRD เครื่องคำนวณเรตรถจักรยานยนต์สำหรับ Streamlit

## สร้างแอปใหม่
1. แตกไฟล์ ZIP
2. สร้าง GitHub Repository ชื่อ srd-motorcycle-rate
3. อัปโหลด app.py, calculator.html และ requirements.txt ไว้ระดับบนสุดของ Repository
4. เข้า https://share.streamlit.io/ และเข้าสู่ระบบด้วย GitHub
5. เลือก Create app แล้ว Yup, I have an app
6. Repository: kanitta0098-sys/srd-motorcycle-rate
7. Branch: main
8. Main file path: app.py
9. กด Deploy และรอแอปพร้อมใช้งาน

ไม่ต้องตั้งค่า GitHub Pages และไม่ต้องอัปโหลด ZIP ทั้งก้อนลง Streamlit

## เพิ่มเป็นหน้าในแดชบอร์ดเดิม
ถ้าแดชบอร์ดใช้ระบบ pages/ ของ Streamlit ให้วาง app.py และ calculator.html ไว้ด้วยกันในโฟลเดอร์ pages/ โดยเปลี่ยนชื่อ app.py เป็น 05_Motorcycle_Rate.py
อย่าทับ app.py หรือ requirements.txt เดิม: ให้เพิ่มหรือปรับ dependency streamlit ให้เข้ากันกับแอปเดิมก่อน
ถ้าแอปเดิมใช้ st.navigation หรือเมนูที่เขียนเอง ต้องลงทะเบียนหน้าใหม่นี้ในเมนูด้วย

## ความสามารถ
- ดอกเบี้ยคงที่ต่อเดือนและจำนวนเดือนที่แก้ไขได้ 5 แผน
- เงินดาวน์เป็นบาท พร้อมเปอร์เซ็นต์เทียบราคาสุทธิ
- ปัดค่างวดตามกติกาที่กำหนด: เศษสตางค์ต่ำกว่า .50 ลงหลักสิบ ตั้งแต่ .50 ขึ้นหลักสิบ
- 1954.36 เป็น 1950 และ 1954.60 เป็น 1960
- ติ๊กฟรีทะเบียน พ.ร.บ. ประกัน พร้อมมูลค่าของแถม และส่วนลดเพิ่มเติม
- ยอดเช่าซื้อรวมและยอดคงเหลืออ้างอิงค่างวดหลังปัด
- พิมพ์ A5 แนวนอน หรือ 2 ใบเหมือนกันบน A4

ข้อมูลที่กรอกเก็บเฉพาะเบราว์เซอร์ ไม่ได้บันทึกเป็นฐานข้อมูลกลาง
ถ้าการพิมพ์ภายในกรอบ Streamlit ไม่ทำงาน ให้ดาวน์โหลดเครื่องคำนวณ HTML แล้วเปิดด้วย Chrome/Edge กรอกข้อมูลและพิมพ์โดยตรง ข้อมูลที่กรอกออนไลน์ไม่ย้ายไปไฟล์ดาวน์โหลดโดยอัตโนมัติ

ทดสอบโครงสร้าง Python และการเรียกหน้า HTML แล้ว แต่ยังไม่ได้ deploy บนบัญชี Streamlit ของผู้ใช้
